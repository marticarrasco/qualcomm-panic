# Results

The [predictor evaluation](../docs/predictor/EVALUATION.md) presents the practice and validation results. Its [aggregate evidence](../docs/predictor/assets/evidence.json) records the reported counts and breakdowns. The [text-only summaries](text-only/) cover earlier M3Kang experiments.

Running [`eval.py`](../eval.py) creates a row-level CSV and a JSON manifest in `results/`. Detailed output can include generated solutions for source exercises. Keep these working files in the local checkout. To examine them locally, use the [results viewer](../results-viewer/README.md) or the root-level `run-results-viewer.cmd` on Windows.
